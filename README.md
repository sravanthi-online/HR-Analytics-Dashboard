# HR Analytics Dashboard Using Power BI

## 1. Project Overview
The HR Analytics Dashboard is a data analytics project developed using Microsoft Power BI. It helps analyze employee information and present important human resource metrics through interactive visualizations.

The dashboard provides insights into employee demographics, workforce distribution, attrition, and other HR metrics based on the available dataset.

## 2. Project Objectives
- Analyze employee data in an organized manner.
- Understand workforce distribution across departments.
- Monitor employee attrition and retention.
- Analyze employee demographics and job roles.
- Present HR metrics using interactive dashboards.
- Support data-driven human resource decision-making.

## 3. Tools and Technologies
- Microsoft Power BI
- Microsoft Excel or CSV dataset
- Power Query for data cleaning and transformation
- Data modeling
- DAX for calculated measures, where applicable

## 4. Dataset Description
The project uses an HR dataset containing employee-related information.

Depending on the dataset, fields may include:
- Employee ID
- Age and Gender
- Department
- Job Role
- Education
- Salary or Income
- Years of Experience
- Job Satisfaction
- Attrition Status

## 5. Data Cleaning and Preparation
- Checked for missing and duplicate values.
- Removed unnecessary columns where appropriate.
- Corrected data types.
- Prepared data for analysis.
- Created calculated measures where required.

## 6. Dashboard Features

### Employee Overview
Provides a summary of the workforce using key performance indicators (KPIs).

### Department Analysis
Shows employee distribution across departments and job roles.

### Attrition Analysis
Analyzes employee departures and attrition patterns.

### Demographic Analysis
Examines employee characteristics such as age, gender, and education, where available.

### Job and Salary Analysis
Explores job roles, salary distribution, experience, and other employment metrics available in the dataset.

## 7. Visualizations
- KPI Cards
- Bar Charts
- Pie or Donut Charts
- Column Charts
- Tables
- Slicers and Interactive Filters

## 8. Project Workflow
1. Collect the HR dataset.
2. Import data into Power BI.
3. Clean and transform the data.
4. Create data models and measures.
5. Design dashboard pages.
6. Add interactive filters.
7. Validate the visualizations.
8. Save and share the completed dashboard.

## 9. Benefits
- Simplifies HR data analysis.
- Helps identify employee attrition patterns.
- Improves workforce visibility.
- Presents HR information clearly.
- Supports informed decision-making.

## 10. Future Enhancements
- Add additional HR performance indicators.
- Improve interactive filtering.
- Include historical workforce comparisons.
- Develop attrition prediction using machine learning, if required.

## 11. Conclusion
The HR Analytics Dashboard demonstrates how Microsoft Power BI can transform employee data into meaningful visual insights. It helps users explore workforce distribution, attrition, and other HR metrics through interactive dashboards.
